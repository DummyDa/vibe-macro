# Vibe Macro

Клиентский Fabric-мод для Minecraft Java Edition **26.1.2**. Выполняет настраиваемый сценарий нажатий клавиш и кнопок мыши с задержками в миллисекундах.

## Установка

1. Установите Fabric Loader для Minecraft 26.1.2 и Java 25.
2. Положите `vibe-macro-1.1.0.jar` и Fabric API в папку `mods`.
3. Запустите игру. Мод автоматически создаст `config/vibemacro.txt`.

## Управление

- `F8` — запустить или немедленно остановить макрос.
- `F9` — перечитать активный профиль с диска.
- `F10` — открыть внутриигровой редактор профилей.
- Клавиши можно переназначить в обычном меню Minecraft: **Настройки → Управление → Назначение клавиш → Vibe Macro**.

При остановке, выходе из мира или ошибке мод отпускает все кнопки, которые удерживал.

## Настройка сценария

Нажмите `F10`, чтобы открыть редактор прямо в Minecraft. В нём можно:

- переключаться между профилями;
- создавать новый профиль на основе текущего;
- удалять ненужные профили;
- редактировать, проверять и сохранять сценарий;
- запускать и останавливать макрос.

Профили хранятся в `.minecraft/config/vibemacro/profiles/`. Старый файл `.minecraft/config/vibemacro.txt`, если он существует, автоматически импортируется при первом запуске новой версии.

```text
# Комментарий
TAP ATTACK 35   # нажать ЛКМ на 35 мс
WAIT 64         # ждать 64 мс
PRESS W         # зажать W
RELEASE W       # отпустить W
LOOP 40         # выполнить всё от начала до этой строки всего 40 раз
```

Команды не чувствительны к регистру:

- `PRESS кнопка` / `RELEASE кнопка` — зажать / отпустить;
- `TAP кнопка [мс]` — короткое нажатие (по умолчанию 35 мс);
- `WAIT мс` — пауза;
- `LOOP количество` — повторить весь сценарий от первой команды до этой строки указанное число раз. Несколько `LOOP` работают вложенно, как в пресете со скриншота.

Доступные кнопки: `W`, `A`, `S`, `D`, `SPACE`/`JUMP`, `SHIFT`/`SNEAK`, `CTRL`/`SPRINT`, `ATTACK`/`LMB`/`MOUSE1`, `USE`/`RMB`/`MOUSE2`.

Стартовый сценарий уже повторяет действия со скриншота: ЛКМ, W и A по 9200 мс (с тремя короткими паузами после ЛКМ), 40 проходов, затем S на 48 секунд; весь блок — 10000 раз.

Используйте макрос только там, где это разрешено правилами сервера.

## Сборка

Нужен JDK 25:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25.0.2'
.\gradlew.bat build
```

Готовый файл появится в `build/libs/`.
