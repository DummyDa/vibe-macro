# Vibe Macro

Клиентский Fabric-мод для Minecraft Java Edition **26.1.2**. Выполняет настраиваемый сценарий нажатий клавиш и кнопок мыши с задержками в миллисекундах.

## Установка

1. Установите Fabric Loader для Minecraft 26.1.2 и Java 25.
2. Положите `vibe-macro-1.0.0.jar` и Fabric API в папку `mods`.
3. Запустите игру. Мод автоматически создаст `config/vibemacro.txt`.

## Управление

- `F8` — запустить или немедленно остановить макрос.
- `F9` — перечитать сценарий с диска.
- Клавиши можно переназначить в меню Minecraft: **Настройки → Управление → Назначение клавиш → Vibe Macro**.

При остановке или выходе из мира мод отпускает все кнопки, которые удерживал.

## Настройка сценария

Откройте `.minecraft/config/vibemacro.txt` в текстовом редакторе. После сохранения нажмите `F9` в игре.

```text
TAP ATTACK 35   # нажать ЛКМ на 35 мс
WAIT 64         # ждать 64 мс
PRESS W         # зажать W
RELEASE W       # отпустить W
LOOP 40         # повторить блок всего 40 раз
```

Команды: `PRESS`, `RELEASE`, `TAP`, `WAIT`, `LOOP`. Доступные кнопки: `W`, `A`, `S`, `D`, `SPACE`/`JUMP`, `SHIFT`/`SNEAK`, `CTRL`/`SPRINT`, `ATTACK`/`LMB`, `USE`/`RMB`.

Стартовый сценарий повторяет действия со скриншота: ЛКМ, W и A по 9200 мс, 40 проходов, затем S на 48 секунд; весь блок — 10000 раз.

Используйте макрос только там, где это разрешено правилами сервера.
